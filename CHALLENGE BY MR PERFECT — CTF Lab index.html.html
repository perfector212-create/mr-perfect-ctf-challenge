Hacker Tips

Getting started

Always check page source (Ctrl/Cmd+U) and browser DevTools console/network first. Try every input field with unexpected characters like ' and <>.

Flag 1 — SQL Injection

The login form builds a query from your input. Classic bypass payloads end a string early and force the condition true, e.g. ' OR '1'='1 or comment out the rest with admin'--. Try them in the username field.

Flag 2 — Stored XSS

The guestbook filters <script> tags but may miss other ways to run JavaScript, like event handlers on an image tag, e.g. an <img> with a broken src and an onerror attribute.

Flag 3 — IDOR

Your profile loads by ID. What happens if you call viewProfile() with a different numeric ID than your own in the console? Admin accounts often have low IDs like 1000 or 1001.
